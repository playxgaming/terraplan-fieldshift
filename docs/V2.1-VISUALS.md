# TerraPlan V2.1 — visual update

Added an interactive, illustrative WebGL farm on Welcome and Overview, plus seven real crop photographs in the gallery and rotation/comparison cards.

Controls: drag to orbit; arrow keys to rotate; +/− to zoom; Golden/Green season for illustrative color changes; Pause/Play motion; reset view. Motion respects reduced-motion preferences and stops outside the viewport or on a hidden tab. A static illustration is used if WebGL is unavailable.

Scoring model remains 2.0.0. The 3D scene is not a field map, forecast or crop-growth simulation. Reference photos are not evidence about the selected field.
